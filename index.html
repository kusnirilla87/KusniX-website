KusniX

From an ordinary person — for ordinary people

Features

Windows Tasks optimization

Disabling Telemetry and Data Collection (RAC, Diagnostics)

Disabling Background Performance Checks (WinSAT)

Disabling Maps, Geolocation, Xbox Live, and the Microsoft Store

Apply all tweaks with a single click

Flexible MMCSS Configuration

Optimizing the Multimedia System Profile (MMCSS) to Reduce Latency

Configuring Audio and Network Traffic Processing Priorities for Systems Using NDIS and NetAdapterCx

Deep System Cleaning

Disabling "Reserved Update Storage" to free up additional space

Clearing the Windows Update cache (SoftwareDistribution) and remnants of uninstalled UWP apps

Network and Interrupt Optimization

Integrated scripts for fine-tuning the network adapter (Ethernet)

MSI (Message-Signaled Interrupts) Management and Assigning Interrupts to Processor Cores

Source code

KusniX Is a free and opensource .bat script with additions, and you can check source code on Github
